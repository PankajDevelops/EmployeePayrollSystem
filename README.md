# Employee Payroll System

A Java-based payroll system that manages employee records and calculates salaries, now enhanced with **JDBC integration** for persistent data storage in a MySQL database. The system supports both **full-time** and **part-time** employees with different salary calculation methods, and provides an interactive **menu-driven interface**.

![Employee Payroll System](https://github.com/user-attachments/assets/af95afe8-68d1-4119-ba44-30cd7ae19107)

## Features

- Add new employees dynamically through console input.
- Remove employees using their unique employee ID.
- Store and retrieve employee data using **MySQL** via **JDBC**.
- Calculate salaries for both full-time and part-time employees.
  - **Full-time Employees**: Monthly salary.
  - **Part-time Employees**: Hourly rate × hours worked.
- Display a list of employees with their details (ID, name, type, salary).
- Handles cases where no employees exist (e.g., “No employees found”).

## Technologies Used

- **Java (Core + Advanced)**: For building the application logic.
- **Object-Oriented Programming (OOPs)**: Applied principles like abstraction, inheritance, and polymorphism.
- **JDBC (Java Database Connectivity)**: For integrating the payroll system with MySQL.
- **MySQL**: To persist employee records.
- **Collections Framework**: Used for handling employee objects in memory.
